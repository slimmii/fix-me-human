In this computer, you write your component in **App.tsx**.

The `.tsx` extension means a TypeScript file can contain **JSX**: markup written inside JavaScript code. It looks much like the HTML you know.

```tsx
<h1>Hello world</h1>
```

`h1` describes a heading. The text between its opening and closing tags is what the user will see.

You do not need any TypeScript type annotations for this first component. Familiar JavaScript is enough.
